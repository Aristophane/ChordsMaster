# Consignes du projet

- Application SPA statique, sans serveur applicatif.
- Le propriétaire autorise la publication sur GitHub Pages. Publier uniquement les fichiers de dist ; les données du carnet restent locales au navigateur.
- Le propriétaire refuse la publication sur ChatGPT Sites. Travailler en local et ne pas synchroniser ni déployer sur Sites sans une nouvelle demande explicite.
- Interface française minimaliste : nom de l'accord, transposition et enregistrement visibles immédiatement sans défilement.
- Pas de textes promotionnels ni de ligne textuelle « Votre position ».
- Afficher les noms chromatiques usuels des notes (Fa, Ré…), en respectant la préférence dièses/bémols. L'analyse interne conserve les degrés et l'orthographe harmoniques corrects.
- Vérifier les changements du moteur avec `npm test` et les changements de mise en page dans l'aperçu local.
